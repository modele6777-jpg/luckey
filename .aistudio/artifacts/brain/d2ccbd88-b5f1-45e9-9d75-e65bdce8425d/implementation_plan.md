# 타로 휠 회전 & 카드 선택 0초 즉시 반응(Zero-Lag) 초경량화 계획

타로 휠을 좌우로 돌릴 때와 카드를 탭하여 뽑을 때 발생하는 버벅임을 근본적으로 해결하기 위해, 매 프레임 발생하던 강제 레이아웃 재계산(Layout Thrashing)과 폭죽 파티클·배경 블러·등장 모션을 전면 제거하고 0초 즉시 반응 모드로 전환합니다.

## User Review & Critical Decisions

> [!IMPORTANT]
> 사용자 답변을 통해 확정된 초경량화 결정 사항입니다.

- **확정 결정 1 (휠 회전 & 카드 탭 동시 최적화)**: 휠을 드래그해 돌릴 때 매 프레임 실행되던 레이아웃 측정(`getBoundingClientRect`)과 78장 `z-index` 강제 변경 루프를 제거하고, 카드를 탭할 때의 메인 스레드 병목을 동시에 해소합니다.
- **확정 결정 2 (폭죽 파티클·배경 블러·슬롯 모션 전면 제거 및 0초 즉시 반응)**: 카드를 뽑을 때 실행되던 폭죽 파티클, 회전하는 휠 위를 덮고 있던 모든 반투명 배경 블러(`backdrop-blur`), 슬롯 등장 애니메이션 지연을 모두 제거하여 탭 즉시(0초) 카드가 슬롯에 꽂히도록 구현합니다.

---

## 1. Overview & Core Concept

- **기능 요약**: 타로 카드 스프레드 화면이 열리는 순간부터 휠을 빠르게 스핀하고 카드를 연속으로 탭하여 뽑기까지 단 1프레임의 멈칫거림도 없는 즉각적인 반응성을 제공합니다.
- **핵심 대상**: 모바일 및 데스크톱에서 타로 휠의 부드러운 회전과 즉각적인 카드 선택을 원하는 사용자.
- **핵심 가치**:
  - 손가락 움직임과 1:1로 즉각 동기화되는 가벼운 휠 회전.
  - 카드를 터치하는 즉시 딜레이 없이 슬롯에 장착되는 0초 반응 속도.

---

## 2. User Experience & Visual Design

- **핵심 사용자 흐름**:
  1. **즉각적인 타로 스테이지 진입**: 진입 시 백그라운드에서 32장의 고해상도 이미지를 동시에 디코딩하며 버벅이던 현상을 없애, 열자마자 부드럽게 휠이 회전합니다.
  2. **무저항 휠 스핀**: 3D 원근 합성(`preserve-3d`)과 매 프레임 78장 `z-index` 재정렬을 제거하고 단일 GPU 평면 회전으로 처리하여, 빠른 스와이프에도 끊김 없이 회전합니다.
  3. **0초 즉시 슬롯 장착**: 카드를 탭하면 폭죽 파티클이나 스케일 애니메이션 대기 없이 즉시 상단 슬롯에 선명한 카드가 표시되고, 휠에서는 양옆 인접 카드만 빈자리를 메웁니다.
- **시각 디자인 및 테마 유지**:
  - **불투명 고대비 다크 서피스 적용**: 회전하는 78장 휠 위에서 매 프레임 배경 픽셀을 실시간 블러 처리하느라 심각한 GPU 병목을 일으키던 상단 안내 바, 카드 슬롯, 하단 컨트롤 바의 `backdrop-blur`를 모두 제거하고 깔끔한 불투명 다크 서피스(`bg-zinc-900`/`bg-zinc-950`)와 골드 보더로 마감합니다.
  - **초경량 휠 카드 뒷면**: 휠에 배치되는 78장의 카드는 무거운 다중 중첩 DOM과 SVG 대신 단일 경량 그래픽 레이어로 렌더링하여 GPU 메모리와 페인트 비용을 최소화합니다.

---

## 3. Key Product Decisions & Trade-Offs

- **결정 1: 드래그 중 강제 리플로우(`getBoundingClientRect` & 78장 `z-index` 루프) 완전 제거**
  - *선택한 방식*: 포인터가 움직일 때마다(`pointermove`) 매 프레임 컨테이너의 `getBoundingClientRect()`를 호출하고 78개 카드 DOM의 `style.zIndex`를 덮어쓰던 로직을 제거합니다. 중심 좌표는 터치 시작(`pointerdown`) 시점에 1회만 캐싱하여 사용하고, 회전 중에는 부모 휠 레이어의 `transform: rotate()`만 단독으로 변경합니다.
  - *이유*: 브라우저에서 DOM 스타일을 수정한 직후 `getBoundingClientRect()`를 호출하면 78장의 카드 레이아웃 전체를 매 프레임 동기식으로 다시 계산(Forced Synchronous Layout)하게 되어 회전 시 심한 끊김이 발생합니다.

- **결정 2: 폭죽 파티클·배경 블러(`backdrop-blur`)·등장 모션 제거 및 이미지 대량 프리로드 중단**
  - *선택한 방식*: 카드 선택 시 렌더링되던 폭죽 파티클 컴포넌트와 `framer-motion` 등장 트랜지션을 제거해 정적 즉시 렌더링으로 교체하고, 스테이지 내 모든 `backdrop-blur` 클래스와 초기 32장 이미지 일괄 프리로드를 제거합니다.
  - *이유*: 회전하는 휠 레이어 위에 `backdrop-blur` 요소가 겹쳐 있으면 매 프레임마다 GPU가 78장의 카드를 오프스크린 버퍼에 다시 그리고 가우시안 블러를 연산해야 하므로 회전과 탭 모두에서 극심한 프레임 드랍을 유발합니다.

## 4. Technical Architecture & Data Strategy *(Technical Reference)*

- **아키텍처 및 렌더링 파이프라인 다이어그램**:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                   Zero-Lag Tarot Wheel Pipeline (0ms)                   │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  [1. Pointer Down (터치 시작)]                                          │
│      └──► 컨테이너 중심 좌표(centerX, centerY) 1회 캐싱                 │
│           (드래그 중 getBoundingClientRect 호출 0회)                    │
│                                                                         │
│  [2. Pointer Move / Spin (휠 회전)]                                     │
│      └──► 부모 휠 레이어 단일 2D transform 업데이트                     │
│           • 78장 자식 z-index 루프 제거 (레이어 재구축 0회)             │
│           • preserve-3d 및 상단/하단 backdrop-blur 전면 제거            │
│           • 휠 전용 초경량 단일 레이어 카드 뒷면 적용                   │
│                                                                         │
│  [3. Pointer Up / Tap (카드 선택 - 0초 즉시 반응)]                      │
│      └──► 선택된 카드 즉시 슬롯 표시 (정적 DOM 렌더링)                  │
│           • 폭죽 파티클(TarotCardFlipParticles) 제거                    │
│           • 슬롯 framer-motion 등장 지연 제거                           │
│           • 뽑힌 카드 양옆 이웃 카드만 국소 이동하여 빈자리 메움        │
└─────────────────────────────────────────────────────────────────────────┘
```

- **데이터 모델 및 상태 전략**:
  - **중심 좌표 Ref 캐싱 (`wheelCenterRef`)**: `pointerdown` 및 창 크기 변경 시에만 중심 좌표를 계산하여 `wheelCenterRef`에 저장하고, `pointermove`에서는 순수 산술 연산(`Math.atan2`)만 수행합니다.
  - **데스크톱 호버 스로틀링**: 마우스 이동 시 매 픽셀마다 `elementFromPoint`를 호출하지 않도록 호버 감지를 경량화하고, 모바일 터치 환경에서는 호버 연산을 완전히 건너뜁니다.
  - **마지막 카드 선택 시 대기 시간 단축**: 마지막 카드를 뽑았을 때 리딩 화면으로 넘어가는 딜레이를 최소화하여 체감 속도를 극대화합니다.
