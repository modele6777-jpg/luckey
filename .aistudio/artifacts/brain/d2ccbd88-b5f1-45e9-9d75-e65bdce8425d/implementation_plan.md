# 하단 반투명 플로팅 독 및 자동 숨김 내비게이션 구현 계획

사용자 요청에 따라 좌측 사이드바를 **화면 하단에 떠 있는 반투명 플로팅 독(Bottom Floating Dock)** 형태로 전환하고, 사용하지 않을 때 자동으로 숨겨지며 하단 호버나 터치로 다시 나타나도록 구현합니다.

---

## 1. 주요 변경 내역 요약
- **배치 위치**: 좌측 고정 레일(Left Rail) $\rightarrow$ **화면 하단 중앙 반투명 플로팅 독 (`fixed bottom-3 left-1/2 -translate-x-1/2`)**
- **본문 레이아웃**: 본문 위로 떠 있는 플로팅 형태(`--sites-sidebar-width: 0px`, `width: 100%`)로 전환하여 좌우 여백 없이 메인 화면을 100% 온전히 사용
- **숨김 및 호출 동작**:
  - 마우스가 벗어나거나 3초간 조작이 없을 시 아래로 부드럽게 슬라이드 다운 숨김
  - 화면 하단 가장자리 호버, 하단 중앙 힌트 핸들 탭, 또는 화면 터치 시 즉시 재노출
- **도구 설명(툴팁)**: 하단 바 위쪽(`bottom-[calc(100%+12px)]`)으로 자연스럽게 떠오르도록 방향 조정

---

## 2. 세부 구현 계획

### A. 하단 가로형 플로팅 독 컴포넌트 (`src/components/navigation/LeftSidebarNav.tsx`)
1. **가로형 플로팅 컨테이너 구성**:
   - `flex-col` 구조를 가로 정렬 `flex-row items-center gap-1.5`로 개편
   - `rounded-2xl` 또는 `rounded-full` 캡슐형 디자인, 초미세 글래스모피즘(Backdrop Blur) 및 오로라 앰비언트 글로우 적용
   - 모바일 좁은 화면에서도 주요 채널과 버튼이 자연스럽게 스크롤되도록 `overflow-x-auto no-scrollbar` 지원
2. **자동 숨김 & 인터랙션 타이머**:
   - 3초 무조작 자동 숨김 타이머 (`setTimeout` 3000ms) 복원
   - 마우스 이동(`onMouseMove`), 터치(`onTouchStart`), 포커스 시 타이머 리셋
   - 숨김 상태일 때 화면 하단 중앙에 은은한 오로라 힌트 핸들 바 표시 및 하단 호버 감지 구역 제공
   - 수동으로 즉시 접을 수 있는 최소화 버튼 제공
3. **아이템 배치 최적화**:
   - 핵심 채널 (LUCY, KEY, LUCKEY)
   - 7대 프리즘 채널 (LUCKEY 클릭 시 가로 확장 아코디언 또는 팝오버)
   - LP 플레이어 미니 버튼 및 프로필 사진 아바타를 가로 독 우측/양단에 컴팩트하게 배치
4. **툴팁 방향 전환**:
   - 기존 좌/우 배치 클래스(`left-[calc(100%+14px)]`)를 상단 배치(`bottom-[calc(100%+12px)] left-1/2 -translate-x-1/2`)로 전환하여 독 위로 말풍선 노출

### B. 본문 레이아웃 및 스타일 조정 (`src/index.css`)
1. **사이드바 너비 변수 0px 복원**:
   - `:root { --sites-sidebar-width: 0px; }`
2. **본문 너비 100% 복원**:
   - `.sites-pinned-main`의 `margin-left`를 `0`으로 되돌리고 `width: 100%`, `max-width: 100%`로 전면 확장
   - 하단 플로팅 독과 겹치는 주요 액션 영역을 고려하여 본문 하단에 안전 패딩 유지
3. **하단 보조 내비게이션 & PWA 배너 정렬**:
   - 화면 중앙 기준으로 깔끔하게 정렬되도록 위치 보정

### C. 버전 관리 및 검증 (`RULE[AGENTS_md]`)
1. `package.json` 패치 버전 업데이트 (`1.4.485` $\rightarrow$ `1.4.486`)
2. `public/version.json` 및 `public/changelog.json`에 하단 플로팅 독 및 자동 숨김 구현 내역 갱신
3. `npm run lint` 및 `compile_applet` 수행하여 무오류 검증
4. Git stage, commit (`v1.4.486`), push 수행

---

## 3. 검증 항목
- 하단 플로팅 독이 화면 중앙 하단에 안정적으로 렌더링되는지 확인
- 마우스/터치 조작 3초 후 아래로 슬라이드되며 힌트 탭만 남는지 확인
- 하단 힌트 탭을 클릭하거나 하단에 마우스를 올렸을 때 독이 즉시 복원되는지 확인
- 메인 화면(루시 대화창, 타로 리딩, 일기 등)이 좌우 빈 공간 없이 100% 채워지는지 확인
- 타입스크립트 린트 및 번들 빌드 성공 여부 확인
