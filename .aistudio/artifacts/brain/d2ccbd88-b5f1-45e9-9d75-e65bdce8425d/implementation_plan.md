# 홀드 드래그 자석 스냅 & 순수 문양 가로 확장형 플로팅 메뉴 바 구현 계획

사용자 요청에 따라 메뉴 버튼에서 **'MENU' 글자를 제거하고 빛나는 클로버 오로라 문양만 단독으로 표시**하며, **홀드 드래그로 자유롭게 이동 후 좌우 가장자리에 자석 스냅**되고 클릭 시 **화면 안쪽으로 가로로 펼쳐지는 플로팅 바**로 구현합니다.

---

## 1. 사용자 요구사항 및 반영 내역
- **메뉴 버튼 비주얼**:
  - 'MENU' 텍스트 제거 $\rightarrow$ **오로라 글로우 링과 빛나는 클로버(Clover) 문양만 컴팩트하게 노출**
  - 깔끔하고 미니멀한 원형/둥근 사각형 플로팅 심볼 (44x44px)
- **홀드 드래그 & 자석 스냅**:
  - 버튼을 누른 채 드래그하여 화면 상하좌우 원하는 위치로 자유롭게 이동
  - 손을 놓으면 화면 좌/우 중 더 가까운 가장자리(16px 여백)로 자석처럼 부드럽게 흡착 스냅
  - 드래그 이동 위치를 `localStorage`에 저장하여 새로고침 후에도 위치 유지
  - 짧은 탭(클릭)과 드래그 제스처를 엄격히 분리하여 오작동 방지
- **가로 확장형 플로팅 바**:
  - 버튼 클릭 시 버튼 위치에서 화면 안쪽을 향해 가로 방향으로 부드럽게 확장
    - 좌측 스냅 시: 우측 방향으로 가로 확장
    - 우측 스냅 시: 좌측 방향으로 가로 확장
  - 가로 바 내에 핵심 채널(LUCY, KEY, LUCKEY), LP 음악 플레이어, 프로필 버튼 및 접기 버튼 포함
  - LUCKEY 클릭 시 7대 여정 채널이 상단에 미려한 팝오버 선반으로 전개
- **자동 숨김 & 인터랙션**:
  - 3초간 비활성 시 또는 바깥 영역 클릭 시 컴팩트 문양 버튼으로 자동 축소

## 2. 세부 구현 계획

### A. 드래그 & 가로 플로팅 바 (`src/components/navigation/LeftSidebarNav.tsx`)
1. **드래그 위치 상태 및 스냅 계산**:
   - `framer-motion`의 `drag` 및 `useMotionValue` 또는 포인터 좌표 관리
   - 드래그 종료 시 `window.innerWidth / 2` 기준으로 좌측(`16px`) 또는 우측(`window.innerWidth - 60px`) 스냅
   - 상하 위치는 뷰포트 내 상단(`60px`) ~ 하단(`window.innerHeight - 80px`) 범위로 안전 클램핑
2. **순수 문양 트리거 버튼**:
   - 텍스트 없이 무지개 오로라 링 테두리와 에메랄드 클로버 아이콘만 깔끔하게 노출
   - 회전 및 펄스 앰비언트 이펙트 적용
3. **가로형 플로팅 컨테이너**:
   - `isOpen` 시 `isLeft` 플래그에 따라 `flex-row` 또는 `flex-row-reverse` 정렬
   - 채널 아이콘, LP 바이닐 재생기, 프로필 아바타를 가로 바에 통합
4. **타이머 및 이벤트**:
   - 3000ms 자동 접힘 타이머
   - 바깥 클릭 감지 백드롭 및 메뉴 선택 시 즉시 접힘

### B. 본문 레이아웃 스타일 (`src/index.css`)
- `:root { --sites-sidebar-width: 0px; }` 및 `padding-bottom: 0` 유지

### C. 버전 관리 및 검증 (`RULE[AGENTS_md]`)
1. `package.json` 패치 버전 업데이트 (`1.4.487` $\rightarrow$ `1.4.488`)
2. `public/version.json` 및 `public/changelog.json`에 가로 플로팅 바 및 순수 문양 드래그 버튼 반영 기록
3. `npm run lint` 및 `compile_applet` 수행하여 무오류 검증
4. Git commit & push 수행

---

## 3. 검증 항목
- 메뉴 버튼에 텍스트 없이 클로버 문양만 예쁘게 표시되는지 확인
- 버튼을 누르고 드래그하여 놓았을 때 좌/우 가장자리에 부드럽게 스냅되는지 확인
- 탭 시 드래그 위치에 맞춰 화면 안쪽으로 가로 플로팅 바가 열리는지 확인
- 3초 무조작 시 또는 바깥 클릭 시 문양 버튼으로 다시 축소되는지 확인
- LP 플레이어 및 프로필 이동 등 모든 기능이 정상 작동하는지 확인
