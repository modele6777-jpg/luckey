# 사이드바 7대 채널 추천 1순위 점 단독 표시 및 루시 채팅 버튼 아이콘 전용 간소화

사이드바 7대 프리즘 채널 아이콘 내부 상단 중앙에 중복으로 나타나던 작은 빛 방울 점(Light Gem)을 모든 상태에서 완전히 제거하여 **오직 추천 1순위 우측 상단 테마 컬러 점만 깔끔하게 보이도록** 정리합니다. 아울러 루시 채팅 화면의 **추천질문 리스트 버튼**과 **상단 자동 읽기(Auto-TTS) 버튼**에서도 텍스트 라벨을 제거하고 아이콘만 남겨 미니멀하고 정돈된 UI를 완성합니다.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> 사용자 답변 및 추가 요청을 통해 확정된 핵심 디자인 결정 사항입니다.

- **Confirmed Decision 1 (7대 채널 상단 중앙 점 완전 제거)**: 활성 및 마우스오버 상태를 포함해 7대 채널 아이콘 내부 상단 중앙에 뜨던 작은 빛 방울 점(`Light Gem`)을 완전히 제거하고, 추천 1순위 채널의 우측 상단 테마 컬러 점만 표시합니다.
- **Confirmed Decision 2 (추천 1순위 테두리 하이라이트 유지)**: 하위 7대 채널 중 추천 1순위 아이콘에는 우측 상단 테마 컬러 점과 함께 은은한 테마 컬러 테두리 및 글로우 하이라이트를 그대로 유지합니다.
- **Confirmed Decision 3 (추천질문 리스트 버튼 아이콘 전용화)**: 루시 대화창 하단의 추천질문 전체보기(라이브러리) 버튼에서 `'추천질문'` 텍스트를 지우고 반짝이는 아이콘(`Sparkles`)만 남깁니다.
- **Confirmed Decision 4 (상단 자동 읽기 버튼 아이콘 전용화)**: 루시 대화창 상단 헤더의 자동 음성 읽기 토글 버튼에서 `'자동 읽기'` / `'자동 읽기 OFF'` 텍스트를 지우고 스피커 아이콘(`Volume2` / `VolumeX`)만 깔끔하게 남깁니다.

## 1. Overview & Core Concept

- **What It Does**:
  1. **사이드바 7대 채널 점 표시 일원화**: 7대 채널 아이콘 내부 상단에 뜨던 장식용 빛 방울 점을 제거하여, 우측 상단의 추천 1순위 점과 겹치거나 시선을 분산시키는 문제를 해결합니다.
  2. **추천질문 리스트 버튼 미니멀화**: 하단 추천 질문 바 좌측의 추천질문 모달 트리거 버튼을 텍스트 없는 컴팩트 아이콘 버튼으로 전환해 가로 스크롤 질문 칩의 가시 영역을 넓힙니다.
  3. **상단 자동 읽기 버튼 미니멀화**: 루시 상단 헤더 우측 도구 모음의 자동 읽기 버튼을 검색·초기화·내보내기 버튼과 동일한 정방형 아이콘 버튼 스타일로 통일합니다.
- **Target Audience / Persona**: 불필요한 시각적 중복 요소와 텍스트 라벨 없이 직관적인 아이콘과 단일 인디케이터로 쾌적하게 탐색하고자 하는 사용자.
- **Key Value**: 사이드바와 루시 상·하단 툴바의 시각적 피로도를 줄이고 아이콘 중심의 통일된 미니멀 인터페이스를 제공합니다.

## 2. User Experience & Visual Design

- **Key User Flows**:
  1. **사이드바 7대 채널 확인**: `LUCKEY` 아코디언을 펼치면 7대 프리즘 채널 중 오직 현재 추천 1순위 채널의 우측 상단에만 테마 컬러 원형 점이 빛나며, 다른 채널을 클릭하거나 마우스를 올려도 아이콘 머리 위에 별도의 작은 점이 나타나지 않습니다.
  2. **루시 상단 자동 읽기 토글**: 상단 헤더 우측의 스피커 아이콘 버튼(`Volume2` / `VolumeX`)을 클릭해 자동 음성 읽기를 켜고 끌 수 있으며, 켜진 상태에서는 에메랄드빛 테마 배경과 은은한 펄스 아이콘으로 상태를 직관적으로 알립니다.
  3. **루시 하단 추천질문 리스트 열기**: 하단 추천 질문 바의 골드빛 `Sparkles` 아이콘 버튼을 누르면 사주·타로·점성술 77선 추천질문 라이브러리 모달이 즉시 열립니다.
- **Visual Identity & Theme**:
  - *Aesthetic Direction*: Minimalist Cosmic Iconography — 텍스트 배지와 중복 장식 점을 덜어내고 색채와 아이콘만으로 상태를 전달합니다.
  - *Color Palette & Mood*:
    - 추천 1순위 점: 각 7대 채널의 고유 테마 컬러(`#ef4444` ~ `#a855f7`) + 라이트/다크 맞춤형 대비 링.
    - 상단 자동 읽기 아이콘 버튼: ON 상태 시 에메랄드 글로우(`text-emerald-600 dark:text-emerald-400`), OFF 상태 시 차분한 슬레이트/화이트 톤.
    - 하단 추천질문 리스트 아이콘 버튼: 앰버·골드 포인트(`text-amber-500 dark:text-amber-400`)와 정방형 라운드 테두리.
- **Interactive Feedback & Motion**:
  - 마우스 오버 시 `title` 및 `aria-label`을 통해 버튼 기능 안내를 유지하고, 클릭 시 부드러운 스케일 피드백(`active:scale-95`)을 제공합니다.

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: 7대 채널 내부 상단 중앙 빛 방울 점(Light Gem) 영구 제거**
  - *Chosen Approach*: 7대 채널 버튼 내부 상단 중앙(`top-1 left-1/2`)에 렌더링되던 작은 원형 점 요소를 제거하고, 우측 상단 모서리(`-top-1 -right-1`)의 추천 1순위 점만 남깁니다.
  - *Why*: 추천 1순위 점 외에 아이콘 위쪽에 또 다른 점이 나타나면 어느 것이 1순위 표시인지 혼란스럽고 시각적으로 거슬리기 때문입니다.
- **Decision 2: 상단 자동 읽기 및 하단 추천질문 버튼의 아이콘 전용화**
  - *Chosen Approach*: 버튼 내부의 `<span>` 텍스트 노드를 제거하고 정방형 패딩(`p-2` 및 `p-1 sm:p-1.5`)과 중앙 정렬 아이콘만 렌더링합니다.
  - *Why*: 상단 헤더의 다른 도구 버튼(검색, 초기화, 내보내기) 및 하단 새로고침 버튼과 동일한 아이콘 전용 규격으로 맞춰 공간 효율성과 일관성을 높입니다.
