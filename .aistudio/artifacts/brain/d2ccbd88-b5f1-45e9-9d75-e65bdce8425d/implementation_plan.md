# 타로 휠 카드 뽑기 60fps 초고속 반응 및 렌더링 최적화 계획

타로 카드를 탭하여 뽑는 순간 발생하는 프레임 드랍(렉)과 터치 반응 지연을 근본적으로 제거하여, 모바일 및 아이폰 환경에서도 즉시 반응하는 60fps 카드 선택 경험을 구현합니다.

## User Review & Critical Decisions

> [!IMPORTANT]
> 사용자 답변을 통해 확정된 두 가지 핵심 최적화 방향입니다.

- **확정 결정 1 (나머지 카드 고정 및 빈자리만 국소 메움)**: 카드를 뽑을 때 78장 전체의 각도와 간격을 다시 계산해 전체 카드를 리렌더링하던 기존 방식을 폐기합니다. 대신 뽑힌 카드 양옆의 인접 카드만 부드럽게 이동해 빈자리를 메우고, 나머지 대다수 카드는 기존 위치와 메모이제이션 상태를 그대로 고정합니다.
- **확정 결정 2 (휠 카드 뒷면 무거운 발광·회전 효과 제거)**: 78장의 휠 카드 뒷면마다 동시에 실행되던 무한 회전(`spin`), 점멸(`pulse`/`ping`), 가우시안 블러(`blur`), 다중 네온 그림자(`box-shadow`/`drop-shadow`) 및 거대 쉬머 레이어를 휠 전용 경량 모드로 전환하여 GPU 합성 부하를 최소화합니다.

---

## 1. Overview & Core Concept

- **기능 요약**: 타로 스프레드 휠에서 카드를 회전하고 탭하여 뽑는 전 과정을 0ms에 가까운 즉각적인 터치 응답과 끊김 없는 60fps 애니메이션으로 동작하도록 렌더링 파이프라인을 개편합니다.
- **핵심 대상**: 모바일(특히 iPhone X/XS 등 고해상도 3x DPR 기기) 및 데스크톱에서 타로 리딩을 진행하는 사용자.
- **핵심 가치**:
  - 카드를 탭하는 즉시 버벅임 없이 슬롯에 안착하는 쾌적한 손맛 제공.
  - 다중 카드(3장~10장 스프레드) 연속 선택 시에도 프레임 저하 없는 일관된 반응 속도 유지.

---

## 2. User Experience & Visual Design

- **핵심 사용자 흐름**:
  1. **휠 탐색 및 스핀**: 78장의 카드가 배치된 원형 휠을 손가락이나 마우스로 부드럽게 회전합니다. 불필요한 카드별 무한 애니메이션이 제거되어 스크롤·스핀이 즉각 손끝을 따라옵니다.
  2. **즉각적인 카드 탭 선택**: 원하는 카드를 탭하는 순간, 전체 휠이 멈칫거리는 현상 없이 해당 카드만 즉시 선택 처리되어 상단 슬롯으로 빠르게 안착합니다.
  3. **자연스러운 빈자리 메움**: 뽑힌 카드의 빈 공간은 전체 휠이 흔들리지 않고 양옆 인접 카드들이 자연스럽게 좁혀지며 빈자리를 메워 시각적 일체감을 유지합니다.
- **시각 디자인 및 테마 유지**:
  - **20종 카드 뒷면 테마 디자인 보존**: 기존의 20가지 타로 뒷면 테마 색상, 신성 기하학 문양(SVG 아이콘), 테두리 프레임의 미학은 그대로 유지하되, 휠에 작게 축소되어 렌더링될 때만 GPU 과부하를 유발하는 블러·무한 회전·중첩 광원 레이어를 정적 고대비 스타일로 대체합니다.
  - **크게 보기(미리보기 모달)**: 덱 뒷면 변경 모달 등 단일 카드를 크게 감상하는 화면에서는 기존의 풍부한 시각 효과를 그대로 유지합니다.
- **인터랙티브 피드백 & 모션**:
  - 카드 선택 시 슬롯 등장 애니메이션과 파티클 이펙트에서도 무거운 SVG 필터(`drop-shadow` 중첩 및 `blur`)를 하드웨어 가속 친화적인 `transform`·`opacity` 기반 경량 파티클로 최적화하여, 카드가 슬롯에 나타나는 첫 프레임의 병목을 완전히 없앱니다.

## 3. Key Product Decisions & Trade-Offs

- **결정 1: 전체 덱 재정렬 대신 인접 카드 국소 보간(Local Gap Closing) 적용**
  - *선택한 방식*: 전체 78장 슬롯 기준 각도를 고정한 상태에서, 뽑힌 카드 주변의 인접 카드(양옆 이웃 카드)에만 각도 보정값(offset)을 부여해 빈자리를 메웁니다.
  - *이유*: 기존에는 카드 1장을 뽑을 때마다 분모(`totalCards`)가 78→77→76으로 바뀌어 남은 77장 전체의 삼각함수(`sin`/`cos`) 좌표가 변하고, 이로 인해 77개의 카드 컴포넌트가 동시에 리렌더링 및 레이아웃 트랜지션을 수행하며 심각한 메인 스레드 렉을 유발했습니다. 국소 보간을 적용하면 90% 이상의 카드가 리렌더링 대상에서 완전히 제외됩니다.
  - *고려했던 대안*: 뽑힌 자리를 아예 빈 구멍으로 남겨두는 방식은 렉은 없지만 연속해서 카드를 뽑을 때 휠에 이가 빠진 듯한 인상을 줄 수 있어, 인접 카드가 빈자리를 메우는 방식이 심미성과 성능을 모두 만족합니다.

- **결정 2: 휠 카드 뒷면(`wheel` / `sm` 사이즈)의 정적 GPU 경량 렌더링**
  - *선택한 방식*: 휠에 배치되는 78장의 작은 카드 뒷면에서는 무한 CSS 애니메이션(`spin`, `pulse`, `ping`), `blur-md`, 다중 `shadow-2xl` 및 `-inset-[100%]` 오버레이 DOM 노드를 제거하고, 깔끔한 정적 벡터 그래픽과 경량 테두리로 렌더링합니다.
  - *이유*: 모바일 브라우저(특히 iOS WebKit)에서 회전하는 부모 레이어 내부의 자식 요소 78개가 각각 독립적인 무한 애니메이션과 블러·그림자를 가지면 매 프레임마다 수십 개의 오프스크린 텍스처를 재합성해야 하므로 프레임 드랍의 주원인이 됩니다.

## 4. Technical Architecture & Data Strategy *(Technical Reference)*

- **아키텍처 및 렌더링 파이프라인 다이어그램**:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        Tarot Wheel Stage (60fps)                        │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  [Pointer Tap / Drag]                                                   │
│         │                                                               │
│         ├──► 1. Spin / Drag: 단일 부모 레이어 rotate3d GPU 합성          │
│         │       (개별 카드 리렌더링 0회, z-index 변경 임계치 스로틀링)    │
│         │                                                               │
│         └──► 2. Card Pick (카드 선택 순간):                              │
│                 │                                                       │
│                 ├─► [고정 카드 (~72장)]                                  │
│                 │    • 기준 각도(localAngle) 불변                        │
│                 │    • React.memo 캐시 100% 적중 (리렌더링 0회)          │
│                 │                                                       │
│                 ├─► [인접 카드 (양옆 이웃 카드)]                         │
│                 │    • 뽑힌 카드 방향으로 국소 각도 보간(Local Fill)     │
│                 │    • 단 2~4장의 카드만 GPU transform으로 빈자리 메움    │
│                 │                                                       │
│                 └─► [경량 카드 뒷면 & 슬롯 안착]                         │
│                      • 휠 뒷면: 블러·무한회전·중첩그림자 제거            │
│                      • 슬롯 안착: drop-shadow 필터 제거, 즉시 이미지 표시 │
└─────────────────────────────────────────────────────────────────────────┘
```

- **데이터 모델 및 상태 전략**:
  - **고정 덱 슬롯 인덱스 유지**: `deck` 배열의 78개 원소 순서를 유지하고, `selectedIds`를 `Set`으로 관리하여 O(1) 조회를 수행합니다.
  - **국소 빈자리 메움 각도 계산(`localAngleOffset`)**: 각 카드의 기본 각도는 `originalIdx * (2π / 78)`로 고정하고, 특정 인덱스의 카드가 뽑히면 그 양옆에 위치한 아직 뽑히지 않은 인접 카드들에만 빈자리를 반씩 채우는 각도 보정값(`gapFillOffset`)을 계산하여 전달합니다.
  - **선택된 카드 즉시 숨김**: 이미 뽑힌 카드는 DOM 트리에서 배열 재정렬을 유발하지 않도록 고정 슬롯에서 즉시 비활성화(`isPicked = true`) 처리합니다.

- **인터랙티브 컴포넌트 및 상태 매핑**:
  - **휠 카드 아이템**: `originalIdx`, `gapFillOffset`, `isPicked`, `isHovered`, `cardBackId`만 비교하는 엄격한 메모이제이션을 통해, 카드를 뽑을 때 실제로 각도가 이동하는 양옆 인접 카드만 업데이트합니다.
  - **휠 전용 경량 뒷면 렌더러**: 휠 모드일 때 `animate-spin`, `animate-pulse`, `animate-ping`, `blur-md`, 무거운 `box-shadow` 및 쉬머 오버레이 DOM을 생략하여 카드당 DOM 노드 수와 페인트 비용을 대폭 절감합니다.
  - **슬롯 안착 애니메이션 및 파티클**: 카드 선택 시 실행되는 파티클 수를 최적화하고 SVG `filter: drop-shadow`를 제거하여, 선택 직후 첫 프레임의 GPU 셰이더 컴파일 지연을 방지합니다.
