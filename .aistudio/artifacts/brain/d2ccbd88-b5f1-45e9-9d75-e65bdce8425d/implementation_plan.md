# 사이드바 럭키(LUCKEY) 채널 추천 1순위 표시 구현 계획

사용자의 현재 대화와 활동 맥락에 기반해 실시간으로 선정되는 **럭키(LUCKEY) 7대 채널 중 현재 추천 1순위 채널**을 사이드바에서 한눈에 알아볼 수 있도록 미니 배지, 은은한 글로우 테두리, 상위 LUCKEY 버튼 연동, 그리고 상세 툴팁 안내를 구현합니다.

### User Review & Critical Decisions

> [!IMPORTANT]
> 사전 질문에서 확정해주신 두 가지 디자인 및 UX 결정을 그대로 반영했습니다.

- **확정 결정 1 (추천 1순위 표시 스타일)**: 추천 1순위로 선정된 럭키 채널 아이콘에 **1순위 미니 배지**, **은은한 테마 컬러 글로우 테두리**, 그리고 마우스 호버 시 **추천 세부 메뉴와 사유를 보여주는 툴팁 안내**를 적용합니다.
- **확정 결정 2 (아코디언 접힘 상태 유지 및 상위 버튼 표시)**: 루시(Lucy)나 Key 화면에서 사이드바를 열 때 7대 채널 목록을 기본으로 접어두는 기존 방식을 유지하되, **접혀 있는 상위 `LUCKEY` 버튼에도 현재 추천 1순위 채널 표시(미니 배지 및 툴팁 안내)**를 함께 노출하여 언제든 직관적으로 확인할 수 있게 합니다.

---

### 1. Overview & Core Concept

- **기능 요약**: 빅뱅 버튼의 순환 추천 엔진과 완벽히 동일한 기준(현재 화면 맥락, 최근 대화 주제, 선택된 문장, 미방문 순환 우선순위)으로 계산된 **현재 추천 1순위 럭키 채널**을 사이드바에 실시간으로 시각화합니다.
- **사용자 가치**: 빅뱅 버튼을 드래그하기 전이나 사이드바에서 직접 채널을 탐색할 때, 지금 나에게 가장 필요한 1순위 럭키 채널이 무엇인지 즉시 파악하고 진입할 수 있습니다.

---

### 2. User Experience & Visual Design

- **주요 UX 흐름**:
  1. **사이드바 열기 (7대 채널 접힘 상태)**:
     - 세 번째 코어 아이콘인 **LUCKEY** 버튼 우측 상단에 현재 추천 1순위 채널의 고유 컬러가 반영된 `1순위` 미니 배지가 표시됩니다.
     - LUCKEY 버튼에 마우스를 올리면 툴팁에 현재 추천 1순위 채널명과 추천 세부 기능(예: `추천 1순위 · ORANGE 소원부적`)이 함께 안내되며, 아코디언이 부드럽게 펼쳐집니다.
  2. **7대 프리즘 채널 펼침 상태 (PROLOGUE ~ EPILOGUE)**:
     - 7개 채널 중 **현재 추천 1순위 채널** 아이콘에 은은한 고유 컬러 글로우 테두리와 배경 오라가 점등되고, 우측 상단 모서리에 `1순위` 마이크로 배지가 표시됩니다.
     - 해당 추천 1순위 채널에 마우스를 올리면 플로팅 툴팁에 `추천 1순위` 태그와 함께 추천 세부 메뉴명 및 맥락 추천 사유가 표시됩니다.
- **시각 디자인 & 테마 조화**:
  - **다크 모드 / 라이트 모드 완벽 대응**: 라이트 모드(따스한 아이보리 배경)와 다크 모드(딥 코스믹 나이트 배경) 각각에서 눈부심 없이 선명하게 읽히도록 대비(WCAG AA 이상)와 글로우 투명도를 조율합니다.
  - **터치 타겟 및 레이아웃 무결성**: 슬림 아이콘 레일(`68px~74px`)의 44×44px 터치 히트박스를 해치지 않도록 배지를 아이콘 우측 상단 모서리에 정교하게 배치합니다.

### 3. Key Product Decisions & Trade-Offs

- **결정 1: 빅뱅 드래그 추천 엔진과의 단일 진실 공급원(Single Source of Truth) 동기화**
  - *선택한 방식*: 빅뱅 버튼 드래그 시 사용되는 순환 추천 엔진의 비파괴 조회(Peek) 결과를 사이드바에서도 동일하게 참조합니다.
  - *이유*: 사이드바에서 '추천 1순위'로 안내된 채널과 빅뱅 버튼을 드래그했을 때 이동하는 추천 1순위 채널이 100% 일치해야 사용자에게 일관된 경험을 제공할 수 있습니다.
  - *고려한 대안*: 사이드바 전용 별도 추천 로직을 두는 방식은 빅뱅 버튼의 추천 결과와 불일치가 발생할 수 있어 제외했습니다.
- **결정 2: 접힘 상태에서의 상위 LUCKEY 버튼 브릿지 표시**
  - *선택한 방식*: 7대 채널이 접혀 있을 때는 상위 LUCKEY 버튼에 추천 1순위 채널의 컬러 점등 배지를 표시하고, 펼쳐지면 개별 1순위 채널 아이콘으로 시각적 포커스가 자연스럽게 이어지도록 설계합니다.
  - *이유*: 불필요한 메뉴 자동 펼침으로 인한 세로 공간 복잡도를 막으면서도, 접힌 상태에서 추천 정보를 놓치지 않게 해줍니다.

### 4. Technical Architecture & Data Strategy *(Technical Reference)*

- **아키텍처 및 컴포넌트 다이어그램**:

```
┌───────────────────────────────────────────────────────────────────┐
│                 Context Navigation Cycle Engine                   │
│  - 현재 경로 + 최근 대화/선택 텍스트 맥락 + 7대 채널 순환 이력 분석 │
│  - 비파괴 추천 1순위 조회 (채널 ID, 세부 메뉴 타이틀, 추천 사유)     │
└─────────────────────────────────┬─────────────────────────────────┘
                                  │ 실시간 동기화 (경로 변경 / 사이드바 오픈 / 대화 갱신)
                                  ▼
┌───────────────────────────────────────────────────────────────────┐
│                    Left Sidebar Navigation                        │
├─────────────────────────────────┬─────────────────────────────────┤
│  [상위 LUCKEY 코어 버튼]        │  [7대 프리즘 채널 리스트]       │
│  - 접힘 상태 시 우측 상단에     │  - 추천 1순위 채널 매칭 판별    │
│    추천 1순위 채널 컬러 배지    │  - 은은한 테마 글로우 테두리    │
│  - 호버 툴팁에 현재 추천 1순위  │  - 우측 상단 '1순위' 미니 배지  │
│    채널명 및 세부 기능 표시     │  - 호버 툴팁에 추천 메뉴/사유   │
└─────────────────────────────────┴─────────────────────────────────┘
```

- **데이터 매핑 및 상태 전이**:
  - 추천 엔진이 반환하는 7대 코어 앱 식별자(`hub`, `orange`, `trinity`, `heal`, `bluebird`, `muse`, `epilogue`)를 사이드바의 7대 프리즘 채널(`/prologue`, `/orange`, `/trinity`, `/heal`, `/bluebird`, `/muse`, `/epilogue`)과 1:1 매핑합니다.
  - 페이지 이동, 사이드바 열림 이벤트, 텍스트 선택, 대화 업데이트 이벤트 발생 시 추천 1순위 상태를 즉시 재계산하여 화면 깜빡임 없이 최신 상태를 유지합니다.
