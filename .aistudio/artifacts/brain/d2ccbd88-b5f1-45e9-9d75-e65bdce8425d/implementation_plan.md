# LucKey 사주 상담 만세력·TTS·프로필 및 음악 퀵메뉴 고도화 계획

사용자 피드백을 반영하여 LP판 롱프레스 퀵메뉴, 프로필 단독 시 본인 자동 지정, 음력/양력 정밀 만세력 천문 변환, 자동읽기(Auto-TTS) 정상화, 그리고 선택된 프로필 인물 기준 사주·상담 전면 전환을 체계적으로 구현합니다.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> 사전 질의응답을 통해 확정된 두 가지 핵심 방향을 엄격히 준수하여 구축합니다.

- **확정 결정 1 (LP판 메뉴)**: LP판을 길게 누르면(400ms 홀드) 화면 중앙 모달 대신 **LP판 바로 위에 플로팅 퀵 팝오버**가 부드럽게 펼쳐져 즉각적인 트랙 정보 확인, 볼륨 조절, 재생목록 바로가기, 이전/다음곡 및 앰비언트 무드 사운드 토글을 신속히 조작할 수 있도록 합니다.
- **확정 결정 2 (상담 대상 사주 기준)**: 상담 대상 프로필을 변경하거나 선택했을 때, 내 기존 사주 정보 대신 **선택한 프로필 인물의 만세력(4주 8자)과 오행, 점성학 천문 데이터를 메인 단독 기준으로 즉시 전면 전환**하여 루시 AI 상담 프롬프트 및 상단 만세력 뷰에 직결합니다.

## 1. Overview & Core Concept

- **What It Does**:
  1. **LP판 롱프레스 퀵 컨트롤**: 좌측 하단 LP판을 꾹 누르면(홀드) LP판 상단에 감성적인 글래스모피즘 퀵 팝오버가 등장해 한 손으로도 음악과 음향을 직관적으로 제어.
  2. **프로필 1인 단독 시 '본인' 자동 확정**: 프로필 바나 추가 창에서 인물이 1명만 남을 경우 예외 없이 '본인'(`isMe: true`, `relationship: '본인'`)으로 확정하여 모순된 상태 방지.
  3. **음력/양력 정밀 천문 변환 만세력**: 생년월일이 '음력'으로 저장되어도 양력 날짜로 잘못 계산되던 오류를 근본 해결. 1900~2050년 한국 천문연구원 기준 윤달 및 음양력 변환 알고리즘을 도입해 사주 4주 8자와 절기(입춘, 절입시각)를 100% 정밀 산출.
  4. **상담 중 자동읽기(Auto-TTS) 정상화**: AI 답변 완료 후 낭독이 멈추거나 재생되지 않던 원인(동일 텍스트 토글 off 판정 및 중복 콜백 충돌)을 제거하고, 루시의 다정한 음성이 즉각 매끄럽게 발화되도록 보장.
  5. **대상 프로필 기준 즉시 상담 전환**: 대화창에서 선택된 인물의 생년월일과 만세력을 시스템 프롬프트의 1순위 핵심 분석 데이터로 주입하여, "내 기준"이 아닌 "그 사람의 실제 사주와 운명"을 바탕으로 현실적 자문 제공.
- **Target Audience / Persona**: 루시와 1:1 대화 및 사주·궁합·운명 상담을 진행하는 사용자, 상대방(연인, 가족, 동업자)의 사주를 정확히 분석받고 싶은 사용자.
- **Key Value**: 잘못된 음력 만세력 계산 오류 완전 퇴치, 자연스러운 음성 상담 연속성 확보, 직관적인 음악 조작 편의성 증대.

## 2. User Experience & Visual Design

### Key User Flows
1. **LP판 조작**:
   - 짧은 탭: 재생 / 일시정지
   - 더블 탭: 다음 곡 넘기기
   - **400ms 홀드**: 햅틱 피드백과 함께 LP판 바로 위에 플로팅 글래스 퀵 팝오버 오픈. 손을 떼도 팝오버가 유지되며 볼륨 조절 및 곡 선택 후 외부 영역 터치 시 자연스럽게 닫힘.
2. **프로필 전환 및 삭제**:
   - 2인 이상 시 'X' 버튼으로 특정 프로필을 제거할 수 있으며, 마지막 1명이 남으면 관계가 자동으로 '본인'으로 통합.
   - 단독 1인 상태에서는 삭제 버튼이 비활성화되며 항상 '본인' 1인 점괘 모드로 고정.
3. **음력 사주 입력 및 검증**:
   - 프로필 모달에서 '음력'을 선택하고 날짜를 지정하면, 시스템 내부에서 정밀 양력 변환을 거쳐 정확한 24절기와 4주 8자(년간/년지, 월간/월지, 일간/일지, 시간/시지)를 도출하여 안내.
4. **상담 및 자동읽기**:
   - '자동읽기' 토글이 켜진 상태에서 메시지를 전송하면, 루시의 답변이 생성되자마자 0.1초의 지체 없이 맑고 따뜻한 음성으로 자동 낭독 시작.

### Visual Identity & Theme
- **디자인 톤**: LucKey 고유의 딥 오닉스 다크 테마(`bg-neutral-950`), 은은한 앰버/에메랄드/시안 프리즘 네온 광채, 정밀한 보더라인(`border-white/10`).
- **LP 플로팅 퀵 팝오버**: 너비 280px~320px의 슬림 팝오버 카드로 LP판 직상단에 위치하며, 섬세한 백드롭 블러(`backdrop-blur-2xl`)와 컴팩트 컨트롤 적용.

## 3. Key Product Decisions & Trade-Offs

- **결정 1: 정밀 음양력 변환 알고리즘 도입**
  - *접근법*: 한국 표준 음력-양력 변환 데이터 및 윤달 테이블을 내장하여, 외부 네트워크 호출 없이도 1900~2050년 범위의 모든 음력 날짜를 밀리초 단위로 정확한 양력 일자로 변환.
  - *이유*: 사주명리학은 태양의 황도 좌표(24절기)를 기준으로 하므로, 음력 날짜를 양력 날짜로 선변환하지 않고 24절기를 계산하면 1~2달의 치명적 절기 오차가 발생함.
- **결정 2: Auto-TTS 단일 책임 실행자(Single-Runner Mutex) 패턴 적용**
  - *접근법*: `onFinish` 스트림 콜백과 `useEffect` 감시자가 동시에 `playTTSInChunks`를 호출하던 구조를 개선하여, 메시지 고유 ID 기준 단일 락(Lock)을 걸고 `cleanText === activeFullText` 시 무조건 정지(toggle-off)되던 문제를 루시 자동읽기 모드에서는 우회하도록 분기 처리.
  - *이유*: 사용자 클릭에 의한 '재클릭 시 정지' 동작이 백그라운드 자동 낭독 호출에 간섭하는 버그를 원천 차단하기 위함.
- **결정 3: 프로필 독 활성 대상자의 사주 주입 파이프라인 통합**
  - *접근법*: `sendUnifiedMessage` 호출 시 `activeProfiles` 중 주 상담 대상(1인 시 해당 대상자, 다자간 시 선택된 인물 또는 전원)의 프로필을 기본 프로필 삼아 `extraSystemContext`뿐 아니라 시스템 프롬프트의 메인 사주 요약(`sajuObj`, `astro`)을 교체 주입.

### State & Logic Changes
1. **`src/components/trinity/BgMusicPlayer.tsx` & `src/index.css`**:
   - LP판 홀드 시 나타나는 `isDetailMenuOpen`을 LP판 직상단에 뜨는 감성적인 **플로팅 퀵 팝오버**로 리팩토링.
   - 홀드 감지 시 `pointerdown`, `touchstart`, 타이머 취소, 이동 반경 임계값(12px) 정밀화 및 `click` 이벤트 오발화 차단.
2. **`src/lib/koreanLunarCalendar.ts` & `src/lib/sajuAnalysis.ts`**:
   - 한국 천문 표준 음양력 변환기 구축 (1900~2050년 윤달 대응).
   - `calculateDetailedSaju` 및 프로필 분석 함수에서 `lunarSolar === 'lunar'`일 때 양력 일자로 정확히 변환 후 율리우스 적일과 24절기 절입시각 적용.
3. **`src/components/chat/ChatProfileModal.tsx`, `ChatProfileDock.tsx`, `LucyStandalonePage.tsx`**:
   - 프로필 삭제 및 목록 갱신 시 `remaining.length === 1`이면 강제로 `isMe: true`, `relationship: '본인'` 동기화.
   - 1인 남았을 때 삭제 버튼 숨김.
4. **`src/pages/LucyStandalonePage.tsx` & `src/contexts/AppContext.tsx`**:
   - 상담 대상자 프로필이 변경되면, 해당 대상자의 사주와 천문 데이터를 메인 컨텍스트로 전달.
   - `onFinish`와 `useEffect` 간 충돌을 방지하는 `autoTtsExecutionLockRef` 도입 및 `skipToggleStop` 플래그로 음성 출력 100% 보장.
5. **규정 준수**:
   - `package.json`, `public/version.json`, `public/changelog.json` 버전 갱신 (1.4.319 -> 1.4.320).
   - `npm run lint` 및 `npm run build` 검증.
