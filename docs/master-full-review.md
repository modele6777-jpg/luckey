# 마스터 전체 검토 (v1.7.165)

- 마스터 모드는 등록된 201개 도구(기본 15, 심층 186)를 검토한다. 일반 모드는 선택 실행을 유지한다.
- 기본 도구는 입력 요건을 충족한 계산 결과를 전달한다. 기준값 검증이 보류된 숙요·마하보테·카발라는 실행해도 수치 대신 안전한 상징 관점만 전달한다. 홍국기문 검증 보류 정책은 유지한다.
- 심층 도구는 실제 결과를 얻은 뒤 조언·의미·수행 등 정성적 문구만 추출한다. 원본 점수, 확률, 지수, 숫자가 포함된 문구는 전달하지 않는다. 이 문구는 과학적 측정이 아닌 상징적 관점이다.
- 실행 실패·입력 부족·제공할 정성적 관점 없음은 집계에서 제외한다. 마스터 검토 항목 수와 사용 도구 수는 다르다.
- 사용 도구는 실제 AI에 전달한 항목으로 집계하고 이름에 `(상징)`을 붙여 구분한다. 전달은 모델이 모든 항목을 답변에서 활용했다는 독립적 증명이 아니다.
- AI에는 전체 결과의 공통점·차이·충돌을 검토하고 모순을 숨기지 않도록 지시한다. 숫자·카드 추첨·확정적 미래를 지어내지 않는 규칙도 유지한다.
- 도구 개수나 토큰 사용량은 예측 정확성을 검증하지 않는다. 기존 기준값 검사 실패에 대한 v1.7.155 검토 기록은 계속 유효하다.
