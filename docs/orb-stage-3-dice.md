# 오브 3단계 주사위 추첨

- 두 주사위의 각 눈은 Web Crypto로 뽑는다. 범위를 등분하고 남은 난수는 다시 뽑아 각 눈에 같은 확률을 준다. 마스터 목소리는 기존대로 두 눈의 합으로 고른다.
- 타로는 기존 78장 셔플과 정·역방향을 그대로 쓴다. 주사위 선택 시 카드를 한 장 뽑을 때마다 두 주사위를 두 번 굴려 1,296가지 조합을 만든다. 남은 카드 수로 나누고 남는 조합은 다시 굴린다. 이미 멈춘 카드는 보존하고 새로 뽑힌 카드는 후보에서 뺀다. 화면에 마지막으로 사용한 두 눈을 보여 준다.
- 주역 기본 방식은 기존 매화역수 시간 작괘다. 손님이 주사위 방식을 요청하면 `run_divination_tool`의 `ichingMethod: "dice"`로 아래에서 위로 여섯 효를 뽑는다. 순서 있는 36조합 중 32조합을 쓰고 나머지는 다시 굴린다. 6·7·8·9의 확률은 각각 1/8·3/8·3/8·1/8로 동전 세 개 방식과 같다. 이 추첨은 두 주사위 변형이며, 효 해석과 본괘·지괘 계산은 기존 엔진이 맡는다.
- `open_tarot_shuffle`은 선택 화면을 연다. 카드를 뽑는 시점은 손님이 정한다.
