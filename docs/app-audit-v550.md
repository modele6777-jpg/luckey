## 검증

- TypeScript 검사 및 전체 자동 테스트 144개. 오디오 회귀에 중단된 AudioContext가 무음 소스를 실행하지 않고 오류를 반환하는 검사를 추가했다.
- 32개 주요 URL 초기 실행에서 빈 화면·미처리 JS 오류 없음. 상세 목록: `qa/app-routes-v550.json`. 이 검사는 AI API 실패 응답을 모의 처리했으며 모든 기능의 운영 데이터 완전성을 보증하지 않는다.
- 기존 Sites 동기화 시뮬레이션: PC/모바일 갱신·동시 프로필 편집·대화 추가/삭제·오프라인 복원·계정 구분·전송 중 편집 보존 등 통과.
- 브라우저에서 긴 TTS가 서버 503 실패 뒤 같은 기기 음성으로 마지막 문장까지 처리되고, 기기 음성까지 실패하면 버튼에 오류가 표시되는 것을 검증했다. 기기 음성은 테스트 스텁이며 실제 스피커 출력·음색 검증은 아니다.
- 추가 카드 선택기 내용과 빅뱅 표시, 자동 1장 선택 완료 콜백, 결과 카드 크기 및 역방향 이미지 회전 검증.
- 마우스와 모바일 터치 드래그에서 페이지 이동 없음, 화면 전체 클로버·종료 잔상·취소 정리·동작 줄이기 설정과 기존 단일 탭 검증.

## 운영 확인의 한계

운영 사이트 음성 API 직접 진단 요청은 비공개 접근 경계에서 HTTP 403으로 차단되어 음성 생성 공급자의 실제 응답/쿼터를 확인하지 못했다. 최근 Worker 로그 100건은 동기화 요청(200/409)만 포함해 TTS 서버 실패 원인을 확정할 자료가 없었다. 409는 동시 수정의 버전 충돌 응답이므로 그 자체를 데이터 손실로 판정하지 않았다.

iPhone/PWA 실기기의 무음 모드·미디어 음량·블루투스 출력·OS 음성 재생 제약을 이 환경에서 직접 확인하지 못했다. 외부 음악 혼합을 유지하는 ambient 세션은 무음 모드의 영향을 받을 수 있다. 모든 환경의 모든 오류를 제거했다거나 모든 낭독의 완독을 보증하는 결과는 아니다.

## 추가 API·하이라이트 점검

운영 키의 모델 목록 조회는 200, 기본 gemini-3.1-flash-lite 답변 요청은 공급자 과부하 503이었다. 키 오류로 판정하지 않았다. gemini-2.5-flash-lite는 목록에 있어도 실제 요청은 신규 사용자 지원 종료 404로 제외했다. 공급자가 안내한 gemini-3.5-flash-lite를 보조 모델로 사용하되 직접 요청은 시간 초과로 실제 답변 복구까지 확인하지 못했다. 기본/보조 모두 장애이면 오류를 표시한다. 인증·한도 오류는 재시도하지 않고, 스트림 출력이 시작된 뒤에는 중복 생성하지 않는다. 모의 503→보조 JSON/SSE 응답과 인증·한도 단일 호출 회귀 검증을 추가했다.

동일 문장과 중첩 문단의 하이라이트는 단일 소유자만 표시하고 그 소유자만 스크롤한다. 재생 세션·문장 인덱스 변경도 구독 상태에 반영한다.
