# 점술 계산실 구현 (v1.4.545)

프로필(`/profile`) 상단의 **점술 계산실**을 열어 사용한다. 계산 결과는 전체 JSON과 함께 표시하며, ‘루시에게 물어볼 계산값 복사’로 실제 결과만 대화에 전달할 수 있다. 계산 성공 시 기존 통합 활동 기록에 결과를 남긴다. AI API를 호출해 숫자나 명반을 만드는 기능이 아니다.

이 문서는 앞선 `divination-audit.md`의 **당시 미구현 8종**에 대한 후속 구현 범위를 설명한다. 8종을 모두 완성했다고 주장하지 않는다.

## 입력과 시간

- 출생 기반 도구는 공통 날짜·음력·윤달 검증 뒤 계산한다. 지원 연도는 1900~2100년이다.
- 자미두수는 출생 당시 현지 시각을 그대로 사용한다. 이 기준을 화면 결과에 표시한다.
- 베딕 참고값은 기존 지원 도시의 시간대 확인과 생시가 모두 필요하다.
- 점시는 선택한 IANA 시간대에서 실제 UTC 시각으로 변환한 뒤 UTC+8 포국 시각으로 바꾼다. DST 누락·중복 시각은 추측하지 않고 거부한다. PC의 시간대가 달라도 동일한 포국을 얻는다.
- 실제 포국·작괘 결과가 대화에 없는 경우 AI가 임의로 만든 결과를 계산값이라고 말하지 않도록 프롬프트 범위를 갱신했다.

## 검증과 근거

- 전체 자동 테스트 120개 통과. 신규 `tests/divination-engines.test.ts`는 64괘 전수 순열, 6/9 변효, 동전법 1:3:3:1 분포, 입력 누락, 윤달 보류, UTC/DST, PC 시간대 독립성, 중기 환장, 기문 절기 경계 거부를 포함한다.
- 자미두수는 iztro의 공개 예제(2000-08-16 여성 寅시)의 명궁 午·신궁 戌, 주성 수와 사화 수를 확인했다. 라이브러리와의 일치이며 모든 유파의 독립 정답 인증은 아니다.
- 육임은 upstream의 亥将未时 丁巳 고전 예제 배치와 구조를 확인했다. 삼전 전체 취법에 대한 전문가 대조 검증은 추가로 필요하다.
- 기문은 upstream의 2024-01-15 10시 小寒 中元 陽8局 및 여름 음둔 사례를 재현했다.
- 숙요 표와 베딕 근사 계산은 규칙·범위·일관성 테스트이며 독립 전문 명반과 전 구간 정밀도를 입증한 것은 아니다.

## v1.4.546 채팅 연동

루시 일반·프로의 공통 메시지 전송 경로에서 실제 계산값을 추가한다. 기존 프로필 기반 자미두수·숙요·베딕 참고값 주입과 함께, 선별된 도구 중 주역·육임·일반 기문을 이번 질문에 맞게 실행한다.

- 예: ‘주역으로 이직운 봐줘’, ‘육임으로 계약 전망 봐줘’, ‘일반 기문으로 지금 상황 풀이해줘’.
- 주역 실제 6효는 ‘주역 풀이해줘 6효: 6 6 6 9 9 9’처럼 아래→위 입력. 잘못된 입력을 임의 추첨으로 대체하지 않는다.
- 점시 미지정은 메시지 처리 시점. 명시 날짜·시각은 `YYYY-MM-DD HH:mm` 한국시간 기준이며, 다른 시간대는 계산실을 안내한다.
- 설명·정의·수다에서는 작괘하지 않는다. 직접 제공한 계산 결과는 다시 뽑지 않는다.
- 직전 답변에 대한 괘·변효 후속 해석은 저장된 계산 컨텍스트를 재사용한다. 일반·프로의 기존 독립 저장 구조를 유지한다.
- 스트리밍 재시도·축약 복구는 같은 계산값을 사용한다. 실패했다고 새 괘를 뽑지 않는다.
- 홍국기문 별도 수리·토정비결·태을신수 미지원 및 베딕 근사 등의 제한은 유지한다.
- 회귀 검증 총 133개 통과. `tests/chat-divination.test.ts`에서 양쪽 모드의 도구 선택→실제 엔진 실행, 수동 6효, 후속 결과 재사용, 입력 오류, 저장 병합, 재시도 컨텍스트 보존을 검사한다. 실제 유료 AI 응답 생성은 이 검증에 포함하지 않는다.

### 프로필 계산실 저장 및 운명 프리뷰 연동

계산실은 프로필 페이지로 이동했다. 성공한 결과는 기존 계정별 통합 활동 기록 `featureHistory`에 고유 ID·시각·질문·계산값·출생정보 키와 함께 저장한다. 기존 로컬/공유 상태 동기화 경로를 사용하며 최근 저장 자료를 화면에서 불러올 수 있다. 트리니티에는 계산실을 중복 표시하지 않는다.

- 루시·루시프로는 관련 도구를 선택할 때 공통 저장 자료를 참조한다. ‘저장한 괘 해석해줘’ 등 명시 요청은 새 작괘를 생략한다. 과거 질문의 포국은 과거 자료로 표시한다.
- 출생 기반 저장 명반은 현재 상담 대상의 생일·생시·역법·윤달·성별·도시 키와 일치할 때만 참조한다. 오래된 자료는 화면에 표시해도 채팅 참조에서 제외한다.
- 운명 프리뷰는 저장된 현재 상담 대상의 프로필로 `calculateDetailedSaju`를 다시 실행한 같은 결과를 공유한다. 원국·오행·격국·신강약·용신·신살·상징 점수·현재 연운·대운 정보를 실제 값으로 제공하며, 출생정보 누락과 계산상의 제한을 유지한다.
- 공통 계산 자료 참조와 별개로 두 채팅의 대화내역 저장·초기화 구조는 독립적으로 유지한다.

### 프로필 전체 공통 상담 자료

기본정보·운명 관심사/목표/고민·음악·심리/상담 선호·예술·관계 등 `UserProfile`의 모든 의미 있는 섹션을 두 채팅에 공통 주입한다. 사진은 설정 여부만 전달하고 이미지 원본·계정 인증 정보는 포함하지 않는다. 수다 모드에서는 취향과 상담 선호를 참고하며 점술 계산을 강제하지 않는다. 현재 상담 대상 프로필을 우선하며, 재시도에도 같은 자료를 유지한다.
