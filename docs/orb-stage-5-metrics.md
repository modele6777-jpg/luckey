# 오브 5단계 상담 측정

상담을 끝낸 뒤 **상담 시간·사용량 보기**에서 전체 시간, Gemini Live가 보낸 토큰 사용량, 예상 원가, 평균 및 최근 첫 응답 시간을 볼 수 있다. 상담 시간은 처음 연결을 시도한 시점부터 종료까지이며 다시 연결해도 이어서 센다.

- 글 상담은 실제 WebSocket 전송, 누르고 말하기는 입력 종료 신호 전송, 실시간 음성은 마지막으로 달라진 받아쓰기 수신부터 첫 음성 청크의 재생 예약 시점까지 잰다. 받아쓰기 시점은 실제 발화 종료의 근삿값이다.
- 사용량은 수신한 `usageMetadata` 내 입력·출력·전체 토큰을 합산한다. 연결이 끊겨 서버에서 사용량을 받지 못한 답변은 합계에서 빠질 수 있다.
- Render의 `ORB_LIVE_USAGE_PRICES_USD` 환경변수에 `inputText`, `inputAudio`, `outputText`, `outputAudio`의 100만 토큰당 USD 단가를 담은 JSON을 지정한다. 입력·출력의 텍스트/음성 토큰을 구분할 수 있고 단가까지 제공된 경우에 예상 원가를 표시한다. 예상치는 캐시 할인, 세금 및 별도 비용을 반영하지 않는다.
- 측정 데이터는 현재 상담 화면에서만 유지되며 채팅 보고서나 상담 기억에 저장되지 않는다.
