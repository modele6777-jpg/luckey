# 루시 웹 마이크 권한

사용자가 루시 오브나 음성 모드를 시작하면 네트워크 응답을 기다리기 전에 브라우저에 마이크 권한을 요청한다. 일반 입력창은 짧게 탭하면 입력할 수 있고, 눌러 말할 때만 요청한다. 브라우저의 허용 응답 전에는 음성 인식을 시작하지 않는다. 권한 창을 기다리는 중 닫거나 손을 떼면, 늦게 허용된 스트림도 정리한다.

이미 허용한 브라우저에서는 시스템 권한 창이 다시 뜨지 않을 수 있다. 이전에 차단했거나 인앱 브라우저가 마이크를 막는 경우 설정 또는 브라우저에서 직접 열기를 안내한다. 오브는 마이크가 없어도 텍스트로 상담할 수 있다.
