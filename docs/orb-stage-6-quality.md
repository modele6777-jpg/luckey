# 오브 6단계 응답 속도와 품질 검사

- 음성 세션 설정이 끝나면 계산과 해석 카드 모듈을 미리 불러온다. 실제 트리거가 올 때만 계산한다. 동시에 도착한 같은 계산 요청은 한 결과를 함께 쓰며, 선로딩이 실패해도 다음 호출에서 다시 시도한다.
- 도구 호출 전 대기 멘트를 생략하고, 결과 배치가 준비되는 즉시 Gemini로 전송한다. 취소된 호출의 결과는 응답에 포함하지 않는다.
- 도구 결과를 보낸 시점부터 첫 음성 청크가 재생되도록 예약된 시점까지의 평균 지연을 상담 결과 화면에 표시한다.
- 자동 검사는 사주 결과가 기존 엔진과 일치하는지, 생년월일이 없을 때 결과를 꾸미지 않는지, 아직 고르지 않은 타로 카드를 보고하지 않는지, 정확한 예측이나 고위험 전문 판단을 보장하지 않도록 지시하는지 확인한다. 가상의 음성 연결과 엔진 실행을 검사하며 실제 마스터가 어떤 문장을 말하거나 운영 연결이 얼마나 빨라지는지는 별도 환경에서 확인할 수 있다.
