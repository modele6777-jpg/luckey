# 일반 상담 검토와 핵심값 대조 — v1.7.166

## 적용 내용

일반 상담과 마스터 모두 답변 초안을 별도 모델 요청으로 검토한다. 검토가 끝나기 전에는 초안을 화면·기록·낭독·추천 질문에 전달하지 않는다. 검토 중 사용자가 중단하거나 새 질문으로 이전 요청이 대체되면 늦게 도착한 승인을 버린다. JSON 형식 오류·검토 실패·핵심값 충돌은 초안을 승인하지 않는다.

앱 계산 결과와 실제 앱 추첨 기록으로 핵심값 대조표를 생성한다. 일간, 오행 비율, 신강약 점수, 격국, 해당 일간의 오행별 십신 관계, 타로 카드 이름과 정역방향을 검토한다. 명확한 주장 패턴은 코드로도 대조하여 모델이 잘못 승인하거나 수정안에 다른 오답을 넣어도 표시를 차단한다. 계산이 제공되지 않은 개인 일간 단정도 차단하며 일반적인 용어 설명과 구분한다. 한국어 전체 의미를 해석하는 완전한 증명기는 아니며 나머지 표현은 모델 검토에 의존한다.

일반 상담은 Flash-Lite 생성 이후 상위 Flash 검토를 우선한다. 상위 모델을 사용할 수 없으면 별도의 Lite 검토 요청으로 대체할 수 있다. 같은 Lite 계열이 생성·검토를 맡을 수 있으므로 모델 간 완전한 독립성을 주장하지 않는다. 마스터는 기존 Pro·상위 Flash 후보만 사용한다. 일반 모드의 복구 요청에도 계산 근거와 대조표를 유지하고, 검토 단계에 별도 시간을 허용한다. 로컬 서버도 검토 실패를 모의 답변으로 대체하지 않는다.

## 자동 검증

- 사주·오행·십신·점수·격국·직업·이직·연애·재물·건강·미래 보장·생일 없음·없는 날짜·생시 없음·음력·상대 정보 없음·타로 한 장·세 장·의미 설명·도구 개수 과장·인사에 걸친 질문 20개를 일반/마스터 각각 2회, 총 80회 검사했다.
- 실제 계산기를 실행하고 잘못된 초안과 검토 응답을 주입해 근거 전달·오답 차단·수정안 재대조를 검사했다. 이 80회는 실제 LLM 응답 80회의 정확도 평가가 아니다.
- 최신 201개 도구 목록을 포함한 계산·경계·근거·검토·대화·타로 검사 전체 416개가 통과했고 타입 검사와 프로덕션 빌드도 통과했다.
- 브라우저에서는 일반/마스터 모두 생성과 검토 요청이 분리되고, 잘못된 초안 대신 수정 답변만 표시되는지 검사했다. 일반 모드에서 검토 중 중단한 경우 늦은 승인을 표시하지 않으며 추가 생성 요청도 발생하지 않는지 검사했다(생성 1회·검토 1회). 생성 시간 제한과 검토 시간 제한을 분리해 검토 중 기존 생성 타이머가 답변을 끊지 않게 했다. 이 검사는 모의 API 응답을 사용한다.

## 실제 API 검증: 미완료

실제 API는 가상 프로필과 앱 추첨을 사용해 20개 질문 × 2개 모드 × 2회 = 80회를 계획했다. 실행 중인 코드는 당시 195개 목록 기준이었다. 27회가 종료됐으며 5회는 생성·검토 완료, 22회는 공급자 오류로 승인되지 않았다. 남은 53회는 검증되지 않았다. 실패나 중단을 정확도 통과로 집계하지 않는다. 기록: [실제 API 부분 결과](evals/lucy-consultations-live.json).

서버 로그에서 Gemini `429 RESOURCE_EXHAUSTED`와 `generate_content_free_tier_requests`, `gemini-3.6-flash`의 무료 일일 20회 제한을 확인하여 실행을 중단했다. 다른 상위 모델에서도 무료 분당 제한이 발생했다. 결제가 활성화된 충분한 할당량의 Gemini 프로젝트가 필요하며, 연결된 프로젝트의 할당량은 https://ai.dev/rate-limit 에서 확인할 수 있다. 토큰 단가와 무료 할당량 제한은 별개다.

성공한 표본에서는 임수 일간, 화 50%·수 13%, 임수 기준 화=재성·토=관성을 확인했다. 5개 표본이 전체 질문이나 마스터 품질의 검증 완료를 뜻하지 않는다. 일부 답변은 질문과 무관한 공통 생활 처방을 덧붙여 검토 지침을 보완했다. 보완 이후의 전체 실제 응답 재검증은 할당량 제한으로 미완료다.

할당량 문제를 해결한 뒤 재실행할 수 있다. 기존 승인 건을 유지하고 미확인·실패 건만 다시 실행하려면:

```sh
node --use-env-proxy --use-system-ca --import tsx scripts/eval-lucy-consultations.mts --live --resume
```

이 스크립트는 유료 API 요청을 사용하고 무료 할당량 오류를 감지하면 새 검증 예약을 중단한다. 오류·차단·대기 건수와 실제 사용 모델을 별도로 기록한다. 자동 검사와 모델 검토의 통과는 점술의 미래 예측 정확성 또는 모든 서술의 사실성을 입증하지 않는다.
