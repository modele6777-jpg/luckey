# 앱 API 연결 점검 — 2026-10-26

점검 대상: Sites 운영 버전 1.4.474, 배포 소스 e620bc8. 점검 시각: 2026. 10. 26. 오후 10:10:08 (한국 시간).

## 결론

등록된 Gemini 키는 기본 텍스트 모델에서 유효합니다. 앱 전체가 정상 연결된 상태는 아닙니다. 채팅 외 별도 API는 `LUCKEY_API_ORIGIN`이 없어 차단됩니다. 키 값은 출력하거나 파일에 저장하지 않았습니다.

## 영향 범위

공통 `invokeLLM`, `invokeLLMStream`, `invokeLLMStructured` 경로는 루시 채팅, 여러 앱의 상담·해석·일기 생성 등에 사용됩니다. 공통 연결 검사가 통과했다는 뜻이며, 모든 화면의 입력·맥락·응답 스키마를 각각 검증한 것은 아닙니다. 별도 API의 실패 시 로컬 콘텐츠나 공통 AI로 대체하는 기능이 있어, 화면이 표시되어도 해당 API가 정상이라는 뜻은 아닙니다.

## 필요한 후속 수정

실제로 운영되는 AI 서버를 LUCKEY_API_ORIGIN에 연결하거나, 별도 기능들의 서버 처리를 Sites Worker에 구현해야 합니다. 이번 요청에서는 검사와 결과 기록만 수행했으며 키·접근 권한·운영 라우팅은 변경하지 않았습니다.

## 안전한 재검사

`scripts/audit-sites-api.mjs <로컬 Worker 경로> <결과 JSON 경로>`를 실행한 뒤 운영 설정 JSON을 숨김 표준입력으로 전달합니다. 키를 명령행 인수·파일에 넣지 않습니다. 도구는 로컬 Worker와 실제 Google의 짧은 생성 요청 3개만 사용하며, 업스트림 주소가 설정된 별도 API는 추가 검토 없이 호출하지 않습니다. 운영 동기화·릴레이·초기화 API를 호출하지 않습니다.
