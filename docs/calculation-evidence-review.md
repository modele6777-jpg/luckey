# 계산 근거 정직성 변경 (v1.7.155)

등록 목록의 크기는 실행 성공·정확성의 증거가 아니다. 새 채팅은 질문별 기본 도구의 상태와 실제 제공된 데이터만 기록한다. 예전 메시지의 엔진 목록은 새 실행 증거로 표시하지 않는다.

- `calculationAudit`는 도구·상태·AI에 전달했는지를 메시지에 보존한다. 전달은 AI가 그 결과를 반드시 활용했다는 뜻은 아니다.
- 일반 상담은 라우팅한 도구만 계산하며 짧은 인사는 플러스에서도 계산하지 않는다.
- 검증되지 않은 심층 점수의 계산·프롬프트 주입은 새 채팅에서 제외한다. 별도 계산기용 API와 원본 모듈은 보존한다.
- 숙요·마하보테·카발라는 기존 기준값 검사 미해결로 채팅 수치를 보류하고 상징적 참고로 표시한다. 기문은 홍국기문 수치를 제외하고 점시 포국만 전달한다.
- 계산 오류·입력 부족을 성공 배지로 표시하지 않는다. 개별 심층 계산 오류는 격리한다.
- 천문 좌표와 전통 규칙 산출값은 해석·미래 예측의 과학적 정확성을 보증하지 않는다.

## 검사 범위와 남은 한계

변경 전 별도 체크아웃에서 기존 계산기 검사 231개 중 17개 실패를 확인했다. 출력 형식·전체 배지에 관한 검사는 새 동작에 맞춰 수정했다. 변경 후 기존 검사 231개 중 220개 통과, 11개 실패를 확인했다. 새 실행 근거 검사 7개는 모두 통과했다. 브라우저에서도 계산 근거 1개와 상징·입력 부족 상태의 표시를 확인했다.

남은 11개는 변경 전에도 실패하던 삼재/교운·숙요·격국·마하탁사·카발라·홍국기문의 기준값/형식 검사다. 이번 변경으로 그 계산 자체의 정확성을 인증하지 않는다. 심층 계산은 채팅 근거에서 제외하고 관련 기본 도구도 위 정책에 따라 보류한다. 전체 엔진의 기준 자료 대조·수학적 검증은 후속 작업이 필요하다.
