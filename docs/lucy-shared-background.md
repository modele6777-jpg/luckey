# 루시 공통 대화 배경지식 (v1.4.548)

> v1.4.549부터 아래 당일 배경 참조에 별도 장기기억을 추가했다. 후속 항목을 참고한다.

일반 루시와 프로의 화면·메시지 배열·저장소·일일 초기화는 분리한다. 메시지를 전송할 때 같은 계정의 반대쪽 런타임과 저장소를 읽고 AI 시스템 문맥에만 배경 자료로 추가한다. 반대쪽 저장소에 쓰거나 말풍선을 복사·전송하지 않는다.

- 양쪽 모두 같은 루시라는 지침을 적용한다. 일반의 마스터 금지와 프로의 고정 마스터 설정을 유지한다. 과거 발화의 모드 지시는 현재 명령으로 실행하지 않는다.
- 해당 계정에서 읽을 수 있는 당일 대화 중 사용자·AI 텍스트만 참조한다. 시스템 메시지, 기본 인사, 빈 응답, 오류 메시지와 이미지/음성 원본은 제외한다.
- 기본 24,000자 예산에서 최근 발화와 질문 관련 과거 발화를 선택한다. 메시지당 최대 6,000자를 전달한다. 긴 대화의 모든 과거 내용을 무제한 기억하는 구조는 아니다.
- 기존 일일 초기화 이후의 전날 기록을 새로 영구 보관하거나 자동 부활시키지 않는다. 기존 프로필 및 저장된 계산 자료 참조는 계속 유지한다.
- 계정 식별자가 일치하지 않으면 배경 자료를 전달하지 않는다. 스트리밍 및 축약 복구 재시도에는 처음 구성한 같은 배경 자료를 사용한다.

검증: 전체 138개 테스트 통과. 신규 테스트는 양방향 참조, 원본 배열 불변성, 계정·날짜 필터, 첨부 원본 제외, 관련 과거 발화 선택과 모드 경계 지침을 확인한다. 실제 AI 제공자의 기억 회상 품질을 측정한 평가는 아니다.

## v1.4.549 장기기억

화면 기록과 별도로 `lucyLongTermMemory`를 공유 상태에, 계정별 `lucy_long_term_memory_v1:<account>`를 로컬 저장소에 보관한다. 날짜 필터와 일일 초기화 대상이 아니므로 다음 날에도 양쪽 AI 문맥에서 참조한다.

- 메시지 전송 시 현재 기록과 새 사용자 발화를 먼저 저장한다. 상대 창의 읽을 수 있는 기록도 수집하며 AI 정상 완료/축약 복구 후 답변을 보완한다. 적용 후 대화를 통해 수집된 범위를 기억하고, 이미 사라진 과거 기록을 새로 복원한다고 주장하지 않는다.
- 사용자·AI 발화를 구분한 원문 발췌이며 별도 AI 요약을 사실처럼 생성하지 않는다. 메시지당 사용자 약 900자·AI 약 600자의 앞/뒤를 보관한다. 이미지·음성 원본, 시스템 지시, 기본 인사·빈 응답·오류는 제외한다.
- 최대 512개 발췌, JSON UTF-8 기준 128KiB를 유지하며 초과하면 오래된 항목부터 정리한다. 무제한 원문 보관이나 모든 세부 내용의 완전한 회상 기능은 아니다.
- 관련 기억을 최대 약 12,000자 문맥 예산에서 선택한다. 현재 프로필·사용자 정정이 과거 기억보다 우선이며, AI가 했던 추측은 사용자 사실로 확정하지 않는다.
- PC·모바일 공유 상태 병합은 ID와 계정으로 중복을 제거하고 동시 편집 발화를 보존한다. 일일 화면 초기화는 기억 필드를 삭제하지 않는다. 두 화면의 기록 저장과 모드 설정은 계속 독립적이다.

검증: 전체 144개 테스트 통과. 날짜 변경 후 기억 유지, 계정 경계, 기기 간 메모리 병합, 저장 예산, 동기화 변경 감지 검증을 추가했다. 모바일 Chromium에서 전날 기억을 저장한 뒤 일반·프로의 실제 전송 경로가 모두 해당 기억을 포함하는 것을 확인했다(AI 전송은 모의 응답 사용; 유료 제공자의 회상 성능 평가가 아님).
