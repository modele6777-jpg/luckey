# 루시 상담 검증 — 2026-11-06

대상: v1.7.163, 일반 상담과 마스터 모드. 가상 인물(양력 1990-05-17, 14:30, 여성, 서울)을 사용했으며 실제 이용자 대화는 사용하지 않았다. 이 검증은 앱 계산과 답변 전달의 일관성 검사이며 점술의 미래 예측 정확성을 입증하지 않는다.

## 발견 및 수정

- 명시한 점술 도구보다 주제 기반 라우팅이 우선되어 주역·육임·기문 요청 등이 다른 계산으로 전달됐다. 지정 도구를 먼저 적용한다.
- 베딕·숙요·태국·미얀마 점성술 명칭에 포함된 ‘점성술’을 서양 점성술로 중복 인식했다. 수식된 명칭을 구분한다.
- `allowMaster: false`가 도구 선택 경로에서 무시됐다. 라우터까지 정책을 전달하고 일반 페이지의 전체 채널 복원이 마스터 활성화로 이어지지 않게 한다. Plus·Pro는 명시적으로 전체 채널을 유지한다.
- 도구 구현 범위와 필요 입력이 모델 프롬프트에서 누락됐다. 범위와 독립 결과 없는 합의 주장 금지 지침을 복구한다.
- 배포 서버는 마스터 기본 모델과 첫 번째 대체 모델 실패 후 마지막 상위 대체 모델을 시도하지 않았다. 중복 없이 전체 후보를 순차 시도하고 실제 사용 모델을 반환한다. 전부 실패하면 오류를 전달한다.
- 다른 작업자가 동시에 추가한 도구를 포함한 195개 검토 목록을 유지했다.

## 자동 검사

계산·경계·근거·전체 검토·답변 검토·대화 계산·도구 선택·모드 경계 검사 304개 통과. 모델 대체 경로 검사 2개 통과. 타입 검사와 프로덕션 빌드 통과.

브라우저에서는 의도적으로 ‘186개 정밀 계산 완료, 무조건 성공’이라는 잘못된 초안을 제공했다. 생성 1회와 검토 1회가 실행됐고, 검토 중 초안이 화면에 노출되지 않으며 수정된 답변만 표시됐다. 이 검사는 제어된 모의 API 응답을 사용한다.

## 실제 배포 API 확인

동일 질문: ‘사주로 내 기질과 직업 선택에 참고할 점을 알려줘. 결과가 확정적인지도 설명해줘.’

| 항목 | 일반 | 마스터 |
| --- | --- | --- |
| 실제 응답 모델 | gemini-flash-lite-latest | gemini-3.6-flash |
| 독립 답변 검토 요청 | 없음 | gemini-3.6-flash로 완료 |
| 응답 시간 | 약 3.5초 | 성공한 재시도 약 67.7초, 검토 포함 |
| 주요 근거 대조 | 임수, 화 50%, 신강약 17점, 편인격 일치 | 동일 주요 값 및 수 용신 일치 |
| 미래 보장 여부 | 보장하지 않는다고 설명 | 보장하지 않는다고 설명 |

첫 마스터 요청은 HTTP 500으로 실패했고 재시도에서 성공했다. 모델 공급자의 가용성과 지연을 정상이라고 단정하지 않는다. 별도의 짧은 실제 요청은 gemini-3.6-flash로 HTTP 200과 정답 ‘4’를 반환했다. 실제 API 검사는 현행 배포 서버와 수정된 로컬 도구 선택·검토 함수를 연결해 실행했으며, 브라우저 전체 흐름 검사는 위 모의 API 검사와 구별한다.

## 남은 한계

- 일반 답변에서 화 기운을 ‘재성·관성’으로 묶은 표현은 부정확했다. 이 인물의 임수 기준 화는 재성이고 토가 관성이다. 주요 수치가 일치해도 서술 전체가 정확하다는 뜻은 아니다. 일반 모드에는 마스터의 별도 답변 검토가 없다.
- 계산 구현과 일치하는 결과라도 해당 유파의 학술적·경험적 타당성을 증명하지 않는다. 간이 용신·신강약과 상징 자료를 실측 사실로 취급하면 안 된다.
- 표본 1개의 실제 답변으로 일반화할 수 없고 응답은 재생성 시 달라질 수 있다. 마스터도 검토가 모든 오류를 차단한다고 보장하지 않는다.
- 195개는 검토 목록 크기이며 모두 독립된 정밀 계산에 성공했다는 뜻이 아니다. 계산 성공·상징 참고·입력 부족을 구분한다.
