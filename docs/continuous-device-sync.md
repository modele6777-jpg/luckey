# 같은 Google 계정의 자동 데이터 동기화 — v1.7.170

휴대폰과 PC가 동일한 실제 Google 계정으로 로그인한 경로를 수정했다. 기존 Firebase 인증과 계정별 Firestore 저장소를 사용한다.

## 원인 및 변경

기존 자동 버전 동기화는 사용자 조작·활성 세션 중 실행을 미뤘고, 감시하던 `prism:state_changed` 이벤트를 내보내는 저장 경로가 없었다. 여러 하위 앱은 localStorage에만 기록해 수동 동기화가 활동을 수집할 때까지 업로드되지 않았다. 실시간 구독이 오류로 종료돼도 다시 붙지 않는 경로도 있었다.

데이터 동기화를 버전 확인·새로고침과 분리했다. 앱이 보이는 동안 1초 주기로 로컬 저장 변화 여부를 확인하고, 실제 활동 내용이 바뀌었을 때 계정별 sharedState에 게시한다. 화면 조작·AI 생성·음성 재생 상태는 이 데이터 경로를 막지 않는다. 최초 서버 상태를 확인한 뒤 업로드를 시작하며, 전송 실패는 로컬 자료를 유지하고 재시도한다. 화면 이탈 시 아직 수집되지 않은 로컬 변경도 보관한다.

일반 데이터와 프로 채팅 구독은 종료 오류 후 자동 재시도한다. 창 복귀·온라인 전환·pageshow 시 구독을 다시 연결하고 서버 상태를 읽는다. 서버 응답이 장기간 없으면 주기적으로 재검증한다. 프로 채팅의 로컬 메시지·카드 열기 변경도 자동 게시하며, Firestore의 객체 필드 순서 차이 때문에 같은 내용을 반복 게시하지 않게 했다.

짧은 일부 값·항목 수만 비교하던 감지 대신 전체 의미 데이터의 정규화 서명을 사용한다. 수집할 때 생기는 시각 값과 전송 메타데이터만으로 다시 전송하지 않는다. 같은 ID의 일기 수정과 같은 날짜의 오라클 수정은 갱신 시각으로 병합한다. 목표 순서는 최신 수정본을 따르며 같은 시각의 충돌은 기기 방향에 따라 뒤집히지 않게 한다. 단순 병합만으로 수정 시각을 새로 만드는 동작도 제거했다. 프로 대화 초기화 시각은 로컬에도 보관해 오프라인 초기화가 앱 재진입 후 사라지지 않게 하고, 원격 초기화를 받으면 진행 중인 이전 답변도 중단한다.

## 검증 범위

- 동기화·기억·대화 분리·프로필 보존 관련 자동 검사 44개 통과.
- 두 개의 격리된 Chromium 브라우저 프로필에서 실제 동기화 제어기를 실행해 PC→휴대폰, 휴대폰→PC, 동일 항목 수정, 통신 단절 중 수정 후 재연결, 활성 사용 중 전송, 중복 쓰기 수렴을 확인했다. 수동 동기화 호출은 0회였다.
- 실제 프로 채팅 React 훅도 두 프로필에서 실행해 질문·답변·카드 열기 전파, 오프라인 변경 복구, 오프라인 초기화 후 새로고침, 상대 기기의 진행 중 답변 중단을 검증했다.
- 이 브라우저 검사는 격리된 HTTP 시험 서버와 모의 Firestore 전송을 사용한다. 실제 사용자의 Google 로그인 세션이나 Firestore 자료를 가져오지 않았으며, 실제 iPhone Safari에서의 물리적 두 기기 검증과 구분한다.
- 앱 내부의 실제 Google UID와 Firebase 로그인 UID가 같을 때만 계정별 자동 게시 경로를 활성화한다. 로그인 없이 한 임시 진단 요청의 권한 오류는 실제 로그인 계정의 접근 실패 근거로 사용하지 않았다.

휴대폰의 화면 잠금·OS 백그라운드 정지 중에는 웹앱 코드를 계속 실행한다고 보장할 수 없다. 다시 앱을 열면 자동으로 재연결하고 최신 상태를 받는다. 네트워크나 클라우드 서비스 자체가 불가한 동안은 로컬 기록을 유지하며 재시도한다.

```sh
node --import tsx --test tests/continuous-data-sync.test.ts tests/lucy-long-term-memory.test.ts tests/chat-divination.test.ts tests/lucy-shared-background.test.ts tests/lucy-history-isolation.test.ts tests/profile-avatar-persistence.test.ts
node scripts/test-continuous-sync.mjs
node scripts/test-continuous-sync.mjs --pro
```
