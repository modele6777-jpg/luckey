# WebKit 회귀 검사

- 빅뱅 위·아래 이동 검사는 현재 메뉴 순서인 루시 → 오브 → Key → Lucky → 프롤로그를 따라 실제 탭과 목적지를 확인한다. 좌우 조작과 전환 중 스크롤 위치 검사도 함께 실행한다.
- 펼친 점술모드는 루시가 선택된 동안 점술 테이블을 표시한다. 다른 채널로 이동하거나 그 채널에서 다시 시작할 때는 채널을 유지하는지 확인한다.
- 엔진함은 저장한 위치를 복원한 뒤 목록을 스크롤한다. 루시 헤더 탭은 실제 헤더 안의 배경에 닿게 해서 대화 맨 위와 최근 대화 이동을 확인한다.
- 음성 혼합 검사는 실제 음성 모듈을 테스트에서 번들링해 개발 서버와 빌드 서버에서 같은 검사를 실행할 수 있다.
- 기본 WebKit 명령은 배포용으로 빌드한 앱에 연결한다. 테스트 환경의 느린 초기 로딩에는 충분한 시간을 준다.
- 오브 SVG가 빅뱅의 방향 표시 속성과 접근성 속성을 전달하도록 수정했다. 음성 검사에서는 반복 트랙이 처음으로 돌아가는 시점에도 재생의 진행량을 올바르게 계산한다.
- 루시가 백그라운드에서 돌아올 때 페이지 복귀와 같은 최신 대화 이동을 사용해, 저장된 대화가 화면에 반영된 다음 프레임에서 위치를 맞춘다. 사진 선택 복귀와 음성 낭독의 스크롤 규칙을 적용한다.
