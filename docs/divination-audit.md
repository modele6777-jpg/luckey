# 점술 도구 15종 점검

점검 범위: 도구 자동 선택, 입력 검증, 계산값 생성, AI 프롬프트, 사주·출생차트·타로 결과 표시. 점술의 예측 적중률을 측정한 작업은 아니다. 재현 가능한 소프트웨어 오류와 천문·역법 계산의 일관성을 검증했다.

## 공통 수정

- 15종 모두 한국어 명칭 인식과 구현 범위 주입을 테스트했다. 영어 별칭을 추가하고, ‘베딕/숙요/태국/미얀마 점성술’을 서양 점성술로 잘못 선택하던 충돌을 줄였다.
- 잘못된 생년월일·시간은 계산을 중단한다. 생일이 없을 때 1995년 프리셋 별자리나 임의의 개인 차트를 반환하지 않는다.
- 음력 윤달 설정이 출생차트까지 전달된다. Gregorian 1~99년을 JavaScript가 1900년대로 바꾸는 날짜 검증 오류를 수정했다.
- 계산이 없는 도구들끼리 독립적으로 일치했다고 주장하거나, 건강 진단·합격·수익률을 계산 결과처럼 보장하지 않도록 제한했다.
- 사주 세운 결과 필드 `annual2026`은 기존 저장 데이터와 UI 호환을 위해 이름만 유지한다. 내용과 화면 제목은 실제 현재 절기 연도로 갱신된다.

## 검증

- 15종 도구별 이름 인식과 구현 상태, 음력 설·윤달, 수요일 오전/오후, 입춘 직전/직후, 생시 누락, 해외 DST 누락/중복 시간, 한국 역사적 시간대, 2028년 세운 및 KST 일진 날짜를 검사했다.
- Jean Meeus, *Astronomical Algorithms*, 예제 25.b 태양 황경(1992-10-13)과 예제 47.a 달 황경(1992-04-12)을 독립 기준으로 비교한다. 기하/겉보기 황도 좌표와 시간척도 차이를 감안해 각각 0.03도/0.04도 허용 오차를 사용한다. 이는 점술 적중률이나 모든 천문 값의 전 구간 정밀도를 보증하는 검사가 아니다.
- J2000의 목성·토성 위치 범위, 모든 행성의 별자리 내 도수 범위, 78장 카드 및 역방향 사전의 누락·중복을 검사했다.
- 관련 회귀 검증: `tests/divination-audit.test.ts`, `tests/saju-boundaries.test.ts`, `tests/mcp-saju.test.ts`, `tests/lucy-chat-page-mode.test.ts`.

## 남아 있는 범위

자미두수·숙요·베딕·육임·홍국기문·주역 자동 작괘·토정비결·태을신수 8종의 독립 계산기는 이번에 새로 구현하지 않았다. 입력·전통/유파·역법·기준표가 검증되지 않은 계산을 추가하면 정확도가 오히려 떨어진다. 해당 도구는 상징 설명 또는 사용자가 제공한 검증된 결과의 해석으로 한정한다. 서양 차트의 12하우스·트랜짓, 정밀 구성학 방위반, 마하보테 7궁·태국 정밀 차트, 사주의 출생지별 진태양시와 절입 당일 생시 미입력의 다중 후보 계산도 별도 구현 범위다.
