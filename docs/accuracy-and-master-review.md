# v1.7.159 계산·마스터 답변 검토

## 계산 검사

이전 11개 실패에는 실제 실행 오류와 모순된 검사값이 섞여 있었다.

- 홍국기문: 초기화 전 starNameOf 참조를 수정했다.
- 삼재: 비삼재인 해에 등급이 남는 오류를 수정했다.
- 교운: 교체 직후 새 대운을 이미 현재 대운으로 잡아 +0/+1 경계가 사라지는 오류를 수정했다.
- 카발라: 마스터수 11을 1~10 세피로트 조회에 그대로 넘기는 오류를 수정했다.
- 검사값: 숫자 7=네차크/5=게부라, 목성 19년/라후 12년의 일관된 기간, 한자 虚/虛 표기, 순用 오타, 다른 날짜도 자릿수 합이 같을 수 있다는 점을 정리했다.

기존 계산기 검사 231개가 모두 통과했다. 이는 구현한 규칙·기준값의 일관성 확인이며 과학적 예측력 인증이 아니다. 상징·미검증 수치를 실측으로 전환하지 않는다. 이전 문서의 '실패 11개 남음'은 이 변경 이전 상태다.

## 마스터 응답

- Gemini 3.1 Pro Preview를 우선 요청하고, 제한·장애 시 Gemini 3.6 Flash/Flash latest로 대체한다. 일반 Flash-Lite로 조용히 변경하지 않는다. 프록시도 같은 등급을 유지하고 실제 사용 모델을 응답한다.
- 로컬 제공자 연결 검사에서는 Pro가 429, Flash latest/3.8이 503, 3.6 Flash가 200을 반환했다. 계정의 Pro 한도가 해제됐다는 뜻은 아니다.
- 초안 생성 뒤 같은 계산 자료·입력·실행 기록을 검토 모델에 전달한다. 계산 개수 과장·상징의 실측화·없는 개인정보·추첨·확정적 성공을 점검하고 필요하면 답변을 수정한다.
- 검토 결과 형식 오류·취소·검토 실패는 초안 승인으로 처리하지 않는다. 생성 후 저장·표시·TTS는 검토가 끝난 답변으로 진행한다.
- 생성과 검토 두 호출을 사용하므로 이전 Flash-Lite 한 번 기준의 비용·대기시간 추정은 그대로 적용되지 않는다. 모델 검토도 완벽한 사실 검증을 보장하지 않는다.

동시에 병합된 심층 도구 3개를 보존했다. 전체 도구는 189개이며 원본 실행 기록·마스터 검토 연결 검사를 다시 수행한다.
