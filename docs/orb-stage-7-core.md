# 오브 7단계 공통 Lucy Master AI 코어

- `src/lib/lucyToolRegistry.ts`에 세 모드가 함께 쓰는 주요 도구 ID, 음성 실행 조건, 시간·연도 기준 도구의 범위를 두었다.
- `src/lib/lucyMasterCore.ts`는 등록된 도구로 기존 결정론적 계산 엔진을 호출하며, 계산 근거와 해석을 구분하는 지침을 세 모드에 제공한다.
- 루시채팅과 점술모드는 기존 질문 라우터와 모드별 정책으로 도구를 선택한다. 오브 음성모드는 같은 목록으로 Live 함수 선언을 구성하고, 함수가 호출되면 같은 코어로 계산한다. 타로는 각 모드에서 기존에 사용하던 셔플·선택 화면을 사용한다.
- 기존 화면·모드별 깊이·오디오·결과 표시 방식에 영향을 주지 않도록 계산 결과 표시는 각 모드에 둔다.
