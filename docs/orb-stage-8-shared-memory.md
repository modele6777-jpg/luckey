# 루시 8단계 공통 상담 기억

세 모드의 **상담 기억**에서 루시채팅, 루시점술모드, 루시음성모드의 기억을 각각 켤 수 있다. **켜진 모드끼리 기억 공유**도 켜면 출처 모드와 받는 모드 양쪽에 동의가 있는 기록만 다른 모드에 전달한다. 기억 공유의 기본 상태는 꺼짐이다.

- 계정별 공통 저장소는 4단계에 만든 `lucy_consult_memory_v1:<account>`를 이어 쓴다. 같은 기기와 브라우저의 해당 계정에서만 공유된다.
- 모드별 최근 8건을 90일 동안 보관한다. 텍스트 상담은 완료된 답의 고민과 답변을 짧게 발췌하고, 오브는 상담이 끝날 때 고민과 마지막 조언을 기록한다. 다음 답에 전달하는 지난 기억은 출처·날짜와 함께 최대 두 건이며 참고 자료로 표시한다.
- 세 모드의 기록을 같은 화면에서 조회하고, 고민과 조언을 수정하거나 기록을 한 건씩 또는 모두 삭제할 수 있다. 끄면 이후 저장과 모델 참고가 중단된다. 수정과 삭제는 이후 모델 참고에 반영된다.
- 기존 KST 일일 대화 기록과 상담 기억 요약은 각자의 저장 경로를 가진다. 자동으로 다른 모드에 건너가는 정보는 동의한 요약이다. 사용자가 직접 누르는 오브의 **채팅에 남기기**와 루시 점술모드의 **이어서**는 한 번의 명시적 이어보기다.
