# 루시 후속 상담 기억 — v1.7.168

동일 계정의 일반·프로 장기기억에서 현재 질문과 관련된 사용자 발언을 골라 생성과 검토에 함께 전달한다. 기존 저장·동기화 형식을 유지하며 별도 AI 요약 요청을 추가하지 않는다.

- ‘가온회사로 이직하려고 준비 중이야’ 이후 ‘그 회사 면접 봤어’처럼 단어가 완전히 같지 않아도 직업 주제를 연결한다.
- 최신 취소·정정·결정·결과 발언이 검색어가 적어도 함께 전달한다. 이미 알려준 목표나 사실은 다시 묻지 않고, 오래된 준비 상태로 되돌리지 않도록 생성·검토 지침에 반영한다.
- 이름이 다른 회사 후보가 여럿이면 하나로 합치지 않는다. 최근 대화에 대상이 명시됐으면 이를 우선하고, 그래도 불명확하면 한 가지만 확인한다.
- ‘다른 질문인데…’와 같은 명시적 주제 전환은 이전 작업 대화 맥락을 정리한다. 단순 인사나 무관한 질문에 오래된 고민을 자동으로 끌어오지 않는다.
- 루시가 과거에 추측한 내용은 사용자 기억으로 검색하지 않는다. 인용·가정·제삼자 이야기는 원문으로 전달하며 사용자 경험으로 바꾸지 않도록 지시한다.
- 계정별 기억만 읽는다. 계정 정보가 없는 옛 공통 아카이브와 ‘모두 기억한다’는 기존 에피소드 프롬프트는 채팅에 주입하지 않는다. 옛 저장 자료를 삭제하지 않는다.

기억은 무제한이 아니다. 기존 저장 한도(512개 발췌·128KiB)와 별도로 질문마다 사용자 발언 최대 12개, 발췌 약 7,000자 이내를 선택한다. 오래된 일은 당시 발언으로 표시하고 현재 상태를 확정하지 않도록 한다. 한국어 키워드·주제·명시적 지시어로 검색하므로 모든 표현이나 모든 사람의 이름을 완벽하게 연결하지는 못한다. 모호하거나 근거가 없으면 확인 질문을 하도록 한다.

## 검증

대화·기억·검토 관련 검사 40개에서 후속 면접, 결정 취소, 두 회사 구분, 새 주제, 인사, 계정 분리, AI 추측 배제, 오래된 지시어, 예산 제한, 중간 맞장구, 검토 맥락 전달을 확인했다. 기존 장기기억의 날짜 변경·계정 분리·동기화 검사와 기존 에피소드 추출 호환 검사 1개도 통과했다. 타입 검사와 프로덕션 빌드가 통과했다.

브라우저에서는 가상 사용자 발언을 저장하고 실제 채팅 전송을 수행했다. 생성 요청과 검토 요청 모두에 가온회사 목표가 들어가며, 다른 계정 및 옛 공통 아카이브의 ‘금지회사’ 내용은 들어가지 않는지 확인했다. 일반·프로의 후속 답변과 일반 모드의 검토 중 취소, 세 상황을 통과했고 미검토 초안이 장기기억에 저장되지 않는 것도 확인했다. 검토 전 재질문 초안은 숨기고 수정된 후속 답변만 표시한다. API 응답은 통제된 모의 응답을 사용하며 실제 모델의 모든 후속 대화 품질을 입증하는 검사는 아니다.
